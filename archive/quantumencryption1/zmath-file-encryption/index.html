ZMath dual-key file encryption

Encrypted files protected by password, pattern, policy, and provenance.

ZMath is the file-protection layer inside QuantumEncryption1: client-side first encryption, dual-key derivation, authenticated file containers, and controlled policy modes for sensitive organisations.

File encryption

ZMath file container concept

ZMath protects files with password material and pattern-image material before creating a portable encrypted container. QuantumEncryption1 turns that research direction into a deployable enterprise service.

Input

Password plus pattern image

The two inputs make the workflow harder to misuse than a simple password-only file vault. The pattern image becomes part of the key-material equation.

Derive

Salted key derivation

ZMath uses salts, password stretching, SHA-256 style hashing, HKDF-style finalisation, and authenticated encryption so wrong inputs or tampering are detected.

Container

ZME-style encrypted artifact

The encrypted artifact can store algorithm labels, metadata, salts, IVs, mode, and audit references while keeping plaintext out of the public website.

Policy

Portable or exclusive modes

Portable mode can support offline handling. Exclusive mode can bind decryption to a controlled policy token for approved same-domain or private-network workflows.

Secure by restraint

Public site security rule

The public website deliberately does not ask visitors to upload secret files. Live customer environments can be private, local, air-gapped, or deployed inside the organisation's own network.

No plaintext upload

Files are not accepted through this marketing site. Sensitive encryption work belongs in a controlled implementation environment.

No casual account creation

There is no signup wall for attackers to probe. Serious enquiries are manually reviewed.

No public decryption endpoint

Decryption is not exposed as a public cloud service on this domain.

No secrets in the form

The enquiry form warns visitors not to paste secrets, passwords, classified material, or private keys.
